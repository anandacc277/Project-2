ARCHITECTURE OVERVIEW
=====================

User Browser
    ↓
Requests: http://bucket-name.s3-website-us-east-1.amazonaws.com
    ↓
AWS S3 Static Website Hosting
    ├─ Checks requested path
    ├─ If "/" → Serves index.html
    ├─ If not found → Serves error.html
    └─ Returns HTTP response
        ↓
Browser Displays Your Website

CUSTOMIZATION OPTIONS
====================

Change Bucket Name:
  Edit terraform.tfvars
  Change: bucket_name = "my-unique-bucket-name"
  Note: Bucket name must be globally unique across all AWS accounts

Change AWS Region:
  Edit terraform.tfvars
  Change: aws_region = "us-west-2"
  Valid regions: us-east-1, us-west-2, eu-west-1, ap-southeast-1, etc.

Update Website Content:
  1. Edit index.html or error.html
  2. Run: terraform apply
  3. Terraform automatically uploads new files
  4. Refresh browser to see changes

UPDATING YOUR WEBSITE
====================

To Make Changes:
  1. Edit index.html or error.html
  2. Run: terraform apply
  3. Terraform detects file changes
  4. Files are re-uploaded automatically
  5. Refresh browser to see changes (may need cache clear)

To Deploy New Files:
  1. Add new file (e.g., style.css)
  2. Create new aws_s3_object resource in s3.tf
  3. Run: terraform apply

To Change Configuration:
  1. Edit terraform.tfvars
  2. Run: terraform plan (to review)
  3. Run: terraform apply

To Destroy Everything:
  1. Run: terraform destroy
  2. Type: yes to confirm
  3. All AWS resources deleted
  4. Website no longer accessible
  5. Charges stop immediately


TROUBLESHOOTING
==============

Issue: "Bucket already exists"
Solution: Bucket names are globally unique across all AWS
         Change bucket_name in terraform.tfvars to something unique
         Example: my-site-anand-2026-11-19

Issue: "Access Denied" error
Solution: AWS credentials not configured properly
         Run: aws configure
         Enter your AWS Access Key ID and Secret Access Key
         Run: terraform apply again

Issue: Website shows "Access Denied"
Solution: Bucket policy may be propagating
         Wait 30 seconds
         Refresh browser
         Clear browser cache (Ctrl+Shift+Delete)

Issue: Terraform command not found
Solution: Terraform not installed or not in PATH
         Install Terraform: https://www.terraform.io/downloads
         Verify: terraform version

Issue: AWS CLI not found
Solution: AWS CLI not installed
         Install AWS CLI: https://aws.amazon.com/cli/
         Configure: aws configure

Issue: File not uploading
Solution: Verify files exist in project directory
         Check file paths in s3.tf match actual filenames
         Ensure filenames are lowercase (Linux convention)
